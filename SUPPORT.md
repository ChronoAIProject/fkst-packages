# Support

Use GitHub issues for reproducible bugs, documentation gaps, and concrete
enhancement requests.

Before opening an issue:

- Search existing open and closed issues.
- Run `scripts/run.sh doctor` for local environment problems.
- Run the smallest relevant test command when reporting a regression.
- Include package name, command, expected behavior, actual behavior, and relevant
  non-secret output.

Questions about operating `fkst` in a host repository should reference the docs
under [`docs/user/`](docs/user/). Questions about changing package behavior
should reference the docs under [`docs/dev/`](docs/dev/).
