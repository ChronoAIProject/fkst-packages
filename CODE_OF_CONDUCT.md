# Code of Conduct

`fkst-packages` is a technical collaboration space. Contributors are expected to
keep discussion focused, respectful, and useful to the work.

## Expected Behavior

- Be direct without being hostile.
- Critique code, designs, tests, and assumptions rather than people.
- Explain technical tradeoffs with enough context that others can evaluate them.
- Respect maintainer decisions about scope, safety, and repository standards.
- Keep issues and pull requests on topic.

## Unacceptable Behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without permission.
- Repeatedly derailing technical discussion after being asked to stop.
- Submitting malicious code, credential exfiltration, or intentionally unsafe
  operational guidance.

## Reporting

Report conduct concerns to the maintainers through the repository's normal
private contact channel. If no private channel is available, open an issue with
only the minimum public detail needed to request maintainer contact.

Maintainers may remove content, close discussions, block contributors, or take
other action needed to keep the project safe and productive.
